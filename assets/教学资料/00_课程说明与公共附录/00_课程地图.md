# ITA 兴趣社团教学资料整理建议

## 一、结论先行

现有资料不适合按“写作年份”继续堆放，更适合拆成两条课程线：

1. **机器学习与神经网络入门**：概念 → 数学基础 → 训练流程 → 神经网络。
2. **AI 编程入门**：使用边界与术语 → Agent 原理 → 工具实操。

真正属于“同一份材料的重复版本”的主要是《神经网络数学推导》普通版与美化版；其余材料大多是同一概念在不同课程中反复解释，应通过“确定唯一主讲位置 + 其他课程只做简短回顾”来消除重复，而不是简单拼成一份超长讲义。

## 三、哪些内容应该合并

### 1. 将“向量与矩阵”集中到第 2 课

目前第 1 课讲了二维 / 三维 / N 维向量、矩阵、行向量与列向量；第 2 课又从向量转置、特征向量、向量加法和点积开始。两者本来就是一条连续知识链，建议合并成：

1. 向量是什么：从二维到 N 维。
2. 行向量、列向量与矩阵。
3. 向量转置。
4. 特征与特征向量。
5. 向量加法与点积。
6. 多变量函数、偏导数。
7. 线性回归、损失函数与梯度下降。

这样第 1 课可以成为纯概念课，不会在后半段突然切换到数学。

### 2. 将零散术语并成一份“共同术语表”

《机器学习常用术语》中的内容分别在其他讲义中再次出现：

- Loss Function：第 2 课和神经网络讲义已经详细讲解。
- Hyper-plane：神经网络讲义在“线性可分性”中引用。
- Feature Vector：第 2 课已经详细讲解。
- Normalization：目前是相对独立的新内容。

建议把它改为课程附录，而不是一节课。术语表只保留“中英文名称、简明定义、首次出现课程、一个例子”，详细推导放回对应主课。

AI 编程线中的 LLM、token、API、Base URL、API Key、Agent、agent loop 也可收录到同一份术语表，但分成“机器学习术语”和“AI 编程术语”两个小节，不要混排。

### 3. 统一“导数—梯度下降—SGD”的讲解边界

这部分在第 2 课、模型训练讲义、神经网络讲义中都有出现，建议分工如下：

- **第 2 课负责直觉和基础数学**：导数、偏导数、学习率、线性回归中的梯度下降。
- **第 3 课负责训练过程**：前向传播、损失、反向传播、优化器、batch、step、epoch、验证与停止训练。
- **第 4 课负责神经网络公式**：矩阵形式的前向传播、激活函数、梯度、全批量 / 单样本 / mini-batch SGD。

后面的课程只用一个“前课回顾”框复述必要概念，不再重新从头讲一次。

### 4. 统一 batch、step、epoch 与 SGD

《模型训练基础概念讲解》对 batch 和 epoch 的生活化解释更适合初学者，应作为主讲版本；《神经网络数学推导（美化版）》保留公式和三种梯度下降方法的比较，但删减对 step、epoch 的重复定义，改成引用第 3 课。

### 5. 神经网络普通版并入美化版

两份神经网络讲义正文相似度很高，美化版不仅调整了样式，还修正了多处问题，例如：

- 把误写的“权重向量”修正为“偏置向量”。
- 统一矩阵维度中的 `m`、`n` 表述。
- 将 Softmax 的位置从“最后一层隐藏层”修正为“输出层”。
- 修复引号乱码、上下标、公式和标点。
- 增加清晰的标题层级和小节名称。

因此普通版不应继续作为并行版本维护；普通版 PDF 也应归档，之后从美化版重新导出发布 PDF。

## 四、哪些内容需要分开

### 1. 机器学习原理与 AI 编程实践必须分成两条线

机器学习系列回答“模型为什么能学习、数学上发生了什么”；AI 编程系列回答“如何安全、有效地使用现成模型和 Agent 完成编程任务”。学习目标不同，强行合并会让初学者在数学推导和工具操作之间频繁跳转。

两条线只共享少量基础概念，例如 AI、LLM、模型、参数等，可通过共同术语表建立连接。

### 2. AI 伦理与 AI 编程使用边界不要完全合并

第 1 课中的公平、透明、隐私、问责、安全属于社会与系统层面的 AI 伦理；《AI编程…1》中的“不代写作业、检查生成代码、不要过度依赖”属于个人实践规范。两者可以互相引用，但应分别留在各自课程中。

### 3. 稳定原理与工具教程需要分开

Agent 和 agent loop 是相对稳定的概念；TraeWork 的界面、免费额度、按钮位置、模型选项和安装步骤会经常变化。建议在《AI编程…2》中进一步拆成：

- 上半部分：Agent 原理，长期维护。
- 下半部分：TraeWork 操作手册，标注软件版本和更新日期。

以后工具界面变化时，只更新下半部分，不需要重写概念课。

### 4. 可编辑源稿与发布版必须分开

Word 是主源稿，PDF 是发布快照。不要将两者并列放在课程根目录，否则容易误认为是两份不同资料，也容易出现“Word 已更新、PDF 仍是旧版”的情况。

## 五、推荐的最终课程顺序

### A. 机器学习与神经网络入门

1. **A1 人工智能、机器学习与深度学习**
   - AI / ML / DL 的关系
   - 规则程序与数据学习
   - AI 伦理与安全

2. **A2 数学基础、线性回归与梯度下降**
   - 向量、矩阵、转置、特征向量
   - 向量加法与点积
   - 导数与偏导数
   - 单变量 / 多变量线性回归
   - 损失函数与梯度下降直觉

3. **A3 模型训练流程与数据集**
   - 前向传播、损失、反向传播、优化器
   - 训练集、验证集、测试集
   - batch、step、epoch
   - 欠拟合、过拟合、停止训练

4. **A4 神经网络、激活函数与 SGD**
   - 线性 / 非线性与线性可分性
   - 神经网络中的矩阵变换
   - ReLU、Softmax、Sigmoid
   - 梯度的矩阵形式
   - Batch GD、SGD、mini-batch SGD

### B. AI 编程入门

1. **B1 AI 编程基础、边界与 API**
   - 什么情况下适合 / 不适合使用 AI 编程
   - 网页聊天与项目级 AI 编程工具的区别
   - 自然语言、形式语言、LLM、token
   - API、Base URL、API Key 与密钥安全

2. **B2 Agent 原理与 TraeWork 实践**
   - Agent 与普通 LLM 的区别
   - 感知、规划、行动、反馈循环
   - 工作目录与审批机制
   - 工具安装、环境配置和第一次任务

### C. 附录

- C1 中英文术语速查表
- C2 公式速查表
- C3 课堂练习与课后任务（后续补充）

## 七、建议的实际整理顺序

1. 先建立新目录，但保留原目录作为完整备份。
2. 确定每个主题的唯一 Word 主源稿。
3. 合并第 1、2 课中的向量与矩阵内容。
4. 把《机器学习常用术语》改造成公共术语附录。
5. 对梯度下降、batch、epoch、SGD 按课程分工删减重复讲解。
6. 只保留神经网络美化版作为主版本。
7. 给工具教程增加“适用软件版本 / 最后核对日期”。
8. 全部 Word 定稿后统一导出 PDF，旧 PDF 移入历史版本。

## 八、建议补充的内容

目前资料偏“讲解”，课堂活动较少。后续每课最好统一增加四个固定模块：

- 本课目标：学完能回答什么。
- 课前要求：需要会哪些概念。
- 课堂练习：一到两个可当场完成的小任务。
- 一页回顾：只列本课真正需要记住的内容。

统一这四个模块后，不同年份的资料会更像一套课程，而不是若干独立文章。
