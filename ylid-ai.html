INSTALLATION GUIDE

遇到下载提示？按这几步安装

本页下载按钮连接智创协会为 YLIDAI 使用的官方发布源。当前安装包尚未添加 Windows 代码签名，下载量较少时也可能出现信誉提示；该提示本身不是病毒检测结果。请先核对来源，再决定是否继续。

1 · Edge 提示“通常不会下载”
  1. 确认你从本官网 intechassociation.org 点击下载，下载地址的域名为 ylidai-updates.pages.dev。
  2. 打开 Edge 右上角的下载列表，或按 Ctrl + J，找到 YLIDAI 安装包。
  3. 点击文件旁的 “…” → “保留”；如果再次出现提示，选择 “显示更多” → “仍要保留”（部分版本显示“仍然保留”）。
  4. 等待下载完成，再点击“打开文件”。文件名末尾的 (1) 等编号仅表示重复下载，不影响安装。
2 · Windows 提示“已保护你的电脑”

如果提示的是 SmartScreen 阻止了“未识别的应用”，且你已核对上述官方来源并信任该文件，可点击 “更多信息” → “仍要运行”，再按安装向导完成安装。未添加 Windows 代码签名的安装包可能显示“未知发布者”。

如果没有“仍要运行”按钮，可能受到学校或电脑管理员策略限制，请联系管理员协助。

3 · 安装完成后开始使用

打开 YLIDAI，输入管理员或社团发放的访问令牌，验证成功后即可开始对话。后续客户端会验证更新包的 Tauri 签名；此签名用于检查更新来源与完整性，与 Windows 发布者代码签名不同。

以上操作仅适用于“通常不会下载”或“未识别的应用”等信誉提示。如果出现明确的病毒、木马或恶意软件告警，请停止安装并联系社团管理员核查。无需关闭杀毒软件或 SmartScreen。
